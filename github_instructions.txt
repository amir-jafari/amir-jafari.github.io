STEP 1 — CREATE THE GITHUB REPOSITORY
--------------------------------------
1. Go to: https://github.com/new
2. Repository name: amir-jafari.github.io
   (This exact name is REQUIRED — it tells GitHub to host as a Pages site)
3. Set to Public
4. Do NOT initialize with README or .gitignore
5. Click "Create repository"

Your site will be published at: https://amir-jafari.github.io


STEP 2 — INITIALIZE GIT IN YOUR PROJECT FOLDER
------------------------------------------------
Open Terminal and run these commands one at a time:

    cd /Users/ajafari/NAS/GWU/Codes/Website

    git init

    git add index.html css/style.css js/main.js \
            data/publications.json data/publications.js \
            scripts/update_publications.py \
            .github/workflows/update-publications.yml

    git commit -m "Initial personal website"

    git branch -M main

    git remote add origin https://github.com/amir-jafari/amir-jafari.github.io.git

    git push -u origin main



Note: When you run "git push", GitHub may ask for your username and password.
For the password, use a Personal Access Token (not your GitHub account password).
To create a token: GitHub → Settings → Developer settings → Personal access tokens
→ Tokens (classic) → Generate new token → check "repo" scope → copy the token.


STEP 3 — ENABLE GITHUB PAGES
------------------------------
1. Go to: https://github.com/amir-jafari/amir-jafari.github.io
2. Click "Settings" (top tab)
3. Click "Pages" (left sidebar, under "Code and automation")
4. Under "Source": select "Deploy from a branch"
5. Under "Branch": select "main" and "/ (root)"
6. Click "Save"

Wait 2–3 minutes, then visit: https://amir-jafari.github.io
You should see your website live!


STEP 4 — ADD YOUR PROFILE PHOTO (Optional)
--------------------------------------------
1. Put your photo in: /Users/ajafari/NAS/GWU/Codes/Website/assets/photo.jpg
   (Name it exactly "photo.jpg" — the site references this path)
2. Run these commands:

    git add assets/photo.jpg
    git commit -m "Add profile photo"

Your photo will appear on the homepage within a few minutes.


STEP 5 — UPDATING THE WEBSITE IN THE FUTURE
---------------------------------------------
Whenever you make changes to any files, run:

    git add .
    git commit -m "Update website content"
    git push

Changes usually go live within 1–2 minutes.


OPTIONAL — IF YOU GET AUTHENTICATION ERRORS
---------------------------------------------
If git push fails with authentication errors, configure your credentials:

    git config --global user.email "ajafari@gwu.edu"
    git config --global user.name "Amir Jafari"

Then try pushing again with your Personal Access Token as the password.


OPTIONAL — CHECK STATUS AT ANY TIME

================================================================
  HOW TO ADD A NEW PUBLICATION
================================================================

OPTION A — AUTOMATIC (recommended)
-------------------------------------
The GitHub Action in .github/workflows/update-publications.yml runs
automatically every Monday and on every push. It fetches your Google Scholar
profile and adds any new papers to data/publications.json.

To trigger it manually without waiting for Monday:
1. Go to: https://github.com/amir-jafari/amir-jafari.github.io/actions
2. Click "Update Publications from Google Scholar"
3. Click "Run workflow" → "Run workflow"

The action commits the updated JSON automatically and the site reflects
the change within a few minutes.

Note: Google Scholar occasionally blocks automated requests. If the action
fails, use Option B below.


OPTION B — MANUAL
-------------------
Open data/publications.json and add a new object to the "papers" array:

    {
      "year": 2026,
      "title": "Your paper title here",
      "authors": "A. Jafari, Co-Author Name",
      "venue": "Journal or Conference Name",
      "doi": "https://doi.org/10.xxxx/xxxxx",
      "type": "journal",
      "citations": null,
      "highlight": false
    }

Fields:
  year      — publication year (integer)
  title     — full paper title
  authors   — author list as a string
  venue     — journal or conference name / volume info
  doi       — DOI link (or null if none)
  type      — "journal", "conference", or "preprint"
  citations — integer citation count, or null
  highlight — set to true to show in "Most Cited Works" cards

Then commit and push:

    git add data/publications.json
    git commit -m "Add new paper: [short title]"
    git push

The Publications page updates automatically — no HTML editing needed.

================================================================
  HOW TO UPDATE CITATION METRICS (citations / h-index / i10-index)
================================================================

Open data/publications.json and edit the "metrics" block at the top:

    "metrics": {
      "citations": 336,
      "h_index": 8,
      "i10_index": 7
    }

These numbers are also automatically updated by the GitHub Action (Option A above).
